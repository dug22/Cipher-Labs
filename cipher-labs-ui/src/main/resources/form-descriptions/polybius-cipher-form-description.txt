The Polybius cipher uses a 5x5 grid, with the alphabet arranged row by row (I and J are combined). To encrypt each character within the plaintext, you'd locate the letter within the grid and translate it to its appropriate row and column coordinate. For example, to encrypt the letter “A”, you'd locate the letter “A” within the grid and record “11” (meaning row 1 column 1). The decryption process requires you to locate each letter’s row and column coordinate within the grid. For example, “11” would mean “row 1, column 1,” and “A” would be the letter in that coordinate. Cipher Labs lets you create a 5x5 grid using a custom key, following Playfair’s grid mechanic, which involves scrambling the alphabet within the grid.
