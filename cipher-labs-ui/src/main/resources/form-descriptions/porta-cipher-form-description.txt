The Porta Cipher is a polyalphabetic substitution cipher, similar to the Vigenère cipher, except it uses only 13 reciprocal alphabets instead of 26. The Porta tableau contains 13 rows where each letter is grouped into pairs(AB, CD, EF, etc), and 13 columns of letters from A-M. The process of encryption and decryption kind of follows the same principles when working with the Vigenère tableu.
