The Rail Fence cipher (also known as the zigzag cipher) is a classic transposition cipher. To encrypt, the message is written diagonally down and up across a set number of horizontal "rails," then read off row by row. To decrypt, the empty zigzag pattern is reconstructed, filled in row by row with the ciphertext, and then read along the diagonal path to reveal the original message. The key used for this cipher is the number of rails used.
