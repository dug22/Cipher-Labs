Details Behind the Porta Cipher

Little History Behind The Porta Cipher

The Porta cipher is a simple classic poly-alphabetic substitution cipher, which was created by French mathematician Giovannia Battista della Porta in 1563. The original version, consisted of 11 alphabets (22) instead of 13 (26).

Encrypting Using The Tabula Recta

For those of you who are visual learners, The Porta cipher utilizes a 13x13 table featuring 13 distinct rows, where each row is assigned a pair of consecutive letters from the alphabet (such as AB, CD, EF, up to YZ). The column headers consist of the first half of the alphabet (A–M), and each letter pair maps these columns to corresponding rotations of the second half of the alphabet (N–Z).

Now let's say we wish to encrypt the word "SECRET", we would need to choose a key to encrypt our message with. Our key for this example, will just be "KEY". If the key is shorter than the message, in length, repeat writing down the key until it matches the length of the message you wish to encrypt. It should look like this

K E Y K E Y
S E C R E T

From there, you're going to work with the letter pairs that were formed within our table above. The first letter pairs are "KS". First, locate "K" among the row headers (paired letters), and the letter "S" among the column headers. Since "S" is nowhere to be found within column headers, you'd just find the letter "S", among the row "K" is in. The letter that'll return encrypted will be the column header that corresponds with the letter "S". That'll return the letter "A". Next pair is "EE". You'd locate the letter "E" among the rows, and the second letter "E" among the column headers. Based off the intersection, this returns the letter "T". Continuing this process, the next letter pairs are "YC". Locate the letter Y among the rows, and the letter "C" among the column headers. Based off the intersection, the next letter in our ciphertext is "O". Finishing this process returns "ATOMTH" as our final ciphertext. Decrypting Using The Tabula Recta

Decryption follows the same principals of encryption. Write out your key and encrypted cipher text in a table.

K E Y K E Y
A T O M T H

Like before you're going to work with the letter pairs that were formed within our table above. Locate the letter "K" amongst the rows, and the letter "A" amongst the column headers. Based off intersection that returns the letter "S". Same concept, locate the letter "E" amongst the rows, and the letter "T" amongst the column headers. Since the letter "T" doesn't exist within the column headers, find the letter "T" within the row "E" is in, and find the letter that corresponds with "T", within the column headers. That returns the letter "E". Continuing this path, your plaintext returns as "SECRET". Below are some visuals, to highlight the work that's being done.
